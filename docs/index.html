FAQ

Một vài câu hỏi trước khi cài.

T Tube cần Android bao nhiêu?

Bản hiện tại yêu cầu Android 10 / API 29 trở lên và target API 35.

T Tube có tự cập nhật phiên bản trên website không?

Có. Website đọc manifest OTA stable công khai để cập nhật số phiên bản, build, link APK và changelog. Nếu việc đồng bộ tạm thời lỗi, trang vẫn giữ thông tin stable gần nhất.

Email đăng ký được dùng để làm gì?

Email chỉ dành cho thông tin về bản cập nhật T Tube theo phần đồng ý nhận tin. Backend mẫu không lưu IP.

Có thể cài đè bản stable cũ không?

Có khi APK mới giữ cùng application ID và certificate tương thích, đồng thời versionCode đáp ứng điều kiện cập nhật của Android.
